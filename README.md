# CCOT 0.1.0

**China Compliance Operations Toolkit，中国合规运营工具包。** 为 Flarum 提供手机号认证、运营单页、私人工单、帖子图片、私信控制和 IP 属地，复用原生账号与发帖功能，不代替备案和人工运营。

作者：[YerenChina](https://github.com/YerenChina/ccot) · [源码与反馈](https://github.com/YerenChina/ccot) · [Bushcraft中文社区](https://bushcraftcn.com) · [MIT许可证](LICENSE)

## 功能与规则

| 功能 | 用法与注意事项 |
| --- | --- |
| 手机号账号 | 大陆手机号短信注册、密码/验证码登录、短信找回和双号验证换绑；昵称唯一、仅用于展示，系统用户名自动生成，密码与封禁沿用原生规则。未核验手机号不能发帖、回复、点赞或私信；老用户凭原用户名/邮箱和密码登录后给原账号补认证。 |
| 阿里云短信 | 后台填写 AccessKey、签名、模板及验证码变量；保存不发送，授权后才可发送，测试会计费。凭据留空保留，清除会关闭发送；验证码5分钟有效、最多错5次、成功即失效，各用途不可混用。发送频率和额度可设，实际发送失败仍计次数；测试发送须指定号码和额度，默认3次、2小时。 |
| 页脚与单页 | 填写企业、联系邮箱、已办妥的备案号，审核协议、隐私政策、社区规范和常见问题/法规说明；默认文字只是初稿，空备案项不显示，正文不执行HTML。 |
| 私人工单 | 从页脚提交举报、申诉、账号帮助和个人信息申请；本人查看自己的记录，管理员在后台回复、改状态和保全，访客提交后由管理员按联系方式反馈；帖子举报继续用官方Flags。最多3图、每图2MiB，支持JPG/PNG/WebP，上限2000万像素。文字和图片不加密，但图片在非公开目录、仅经授权接口读取。 |
| 工单清理 | 手动删除永久移除工单、回复及图片；保全项须先解除保全，已处理且180天未更新、未保全的记录可由调度自动删除；完整卸载也删除保全项。 |
| 帖子图片与简洁发帖 | 原生新帖、回复、编辑中选图，缩略图按顺序显示，上传完成才能发布，失败可重试；默认上传关闭，开启后默认每帖6图、每图8MiB/2400万像素、总容量2GiB，服务端校正方向并生成2560/480像素长边的WebP，去除定位等元数据，不留原图。**只接收静态JPEG/PNG/WebP，不支持HEIC/HEIF或动画；照片超出限制会上传失败，目前不会在手机端自动压缩。** |
| 图片访问与下架 | **帖子图片是公开静态链接，知道地址即可读取，未发帖、隐藏、待审和分类权限都不保护直链。** 上传及绑定仍校验认证、归属和原生权限；下架将大图/缩略图移出公开目录，不能收回下载或缓存。停用、卸载后静态图继续显示；工单图片不适用此规则。 |
| 私信与属地 | 官方Messages可选，开关同步其启停，用户可拒收或屏蔽；属地离线显示省/国家或地区，不公开原始IP，识别不到显示未知。可选IPv6库通过`ccot.region_v6_file`指定，反向代理须正确传递真实客户端地址。 |

帖子上传每人10分钟20次、每日200次，最多12张待发布图片；复杂正文保留原生源码编辑，第三方附件由原扩展管理。移除图片在帖子保存成功后才解绑；无引用超过7天的图片由站长手动清理，默认仅列候选：

```sh
php flarum ccot:post-images-cleanup
# 核对候选及备份后，才执行永久删除：
php flarum ccot:post-images-cleanup --execute
```

## 环境要求

Flarum **2.0.0 / 2.0.1**、PHP **8.4**、MySQL **8.4**；PHP启用 OpenSSL、Fileinfo、GD/WebP 和 EXIF。正式站使用HTTPS，PHP运行用户须能写入storage、public/assets和论坛配置文件所在目录。

必需扩展：昵称（Nicknames）、BBCode、举报（Flags）、点赞（Likes）、封禁（Suspend）和简体中文语言包；安装命令会自动下载这些扩展及短信、图片处理组件，启用CCOT前请先在后台启用上述扩展。

私信功能另需官方Messages **2.0.0 / 2.0.1**，不使用私信可不安装。

## 安装与首次配置

从**论坛根目录**运行：

```sh
composer config repositories.ccot vcs https://github.com/YerenChina/ccot
composer require bushcraftcn/ccot:"0.1.0"
php flarum migrate
php -d memory_limit=512M flarum cache:clear
```

后台启用CCOT会自动准备私有目录、首次密钥和昵称设置；启用会开放新注册，需暂停时再关闭原生注册开关。

首次配置：**审核单页和联系信息 → 保存短信配置并按需授权 → 按需开启图片/私信 → 核对权限、备份和调度**。自动清理需服务器每分钟从论坛根目录运行`php flarum schedule:run`；CCOT按小时清理过期短期数据及符合条件的工单，不自动删除帖子图片。

## 更新与回滚

先[配套备份](#备份与恢复)并在测试站验证，将下方“目标版本”替换为已发布版本号：

```sh
composer require bushcraftcn/ccot:"目标版本" --with-dependencies
php flarum migrate
php -d memory_limit=512M flarum cache:clear
```

更新沿用原密钥和配置，不用卸载代替升级；失败时保留现场，检查原密钥、文件及权限后重试。回滚须恢复匹配的代码、数据库、配置和图片，评估备份后新增数据的损失，不能只退代码。

## 停用与卸载

**停用：**自动关闭新注册，随后CCOT的登录、认证限制、工单、页面、接口和周期清理全部退出，配置与数据保留；已有用户按原生账号、邮箱验证和权限规则使用，**重新启用自动开放新注册**。

**完整卸载：**先在启用期间打开“卸载准备”，关闭注册、下载并私密保存最新的**手机号—用户名—用户ID HTML对照表**，确认已保存后从本页或原生扩展管理卸载数据；绑定或用户名变化须重新导出，取消准备仍保持注册关闭。已停用但未准备时，先重新启用再准备，此时会先开放注册。

| 删除 | 保留 |
| --- | --- |
| CCOT自有七张表、绑定/验证码/限流/号码限制、全部工单及图片（含保全）、短信私有配置、原密钥、设置/偏好、准备状态、锁文件及接入项。 | 原生账号、密码、昵称、帖子、角色/封禁，帖子图片文件（含私有下架图）及正文链接，其他扩展附件、管理员另存的对照表。 |

卸载成功后开放原生注册、恢复原生登录；用户使用原用户名/邮箱和原密码，系统用户名可由管理员从对照表核实，无邮箱者登录后在原生设置中补真实邮箱并验证，原有封禁不解除；论坛邮件须可用。历史备份、下载、日志和外部缓存不由插件自动清除。

数据卸载成功后再移除代码；若Nicknames和BBCode原为间接依赖，先保留它们，以维持昵称显示和帖子图片解析：

```sh
composer require flarum/nicknames:"2.0.0 || 2.0.1" flarum/bbcode:"2.0.0 || 2.0.1" --no-update
composer remove bushcraftcn/ccot
```

已有直接依赖时省略第一条。卸载中断须保留代码、原密钥和对照表，修正权限后从原生扩展管理重试；重装生成新密钥和空表，不恢复旧绑定/工单或图片索引，已有静态图片仍可读，容量仍计入留存文件。

## 备份与恢复

在停写的一致时间点备份下表，存于受限位置并演练恢复；路径相对论坛根目录，须以实际`site.php`映射和配置为准，不能只备份插件源码。

| 项目 | 范围 |
| --- | --- |
| 数据库 | 完整论坛全部带前缀表，包含原生账号/帖子/权限、设置/迁移及CCOT七表。 |
| 配置与环境 | `config.php`、`site.php`、`extend.php`、论坛`composer.json/lock`、实际插件代码/构建及邮件/代理/调度配置，以及使用中的可选IPv6库。 |
| **原密钥** | 默认`storage/ccot-private/key`，自定义以`ccot.secret_file`为准；原文件必须配套保存，**丢失后无法用新key恢复手机号绑定、短信配置及相关校验**，也不能保证后台继续可用。 |
| 短信配置 | 默认密钥旁`sms-config.enc`；核对`ccot.sms_config_file`及`CCOT_SMS_CONFIG_FILE`覆盖路径，两处已有文件均保存，必要的环境凭据另行私密备份。 |
| 工单图片 | 有效storage下`ccot-ticket-images/`，保存完整目录并与数据库索引配套。 |
| 帖子图片 | 有效public下`assets/ccot-post-images/`及storage下`ccot-post-images-removed/`，大图/缩略图、原生正文和索引须配套。 |
| 其他文件 | 头像、其他扩展附件、自定义资源和管理员另存的对照表，不能因只备份CCOT而漏掉。 |

恢复时停写并保留现场，先还原匹配代码/配置、整库、原密钥及文件，再迁移和清缓存；检查账号、工单越权保护、静态图、短信许可及调度后恢复业务，**不要先启用插件生成替代密钥**。

私有目录须在public外并由PHP用户读写（通常0700/0600），帖子静态目录通常0755/0644；不支持用符号链接替代目录迁移。换域名/网站路径须同步处理正文中的绝对图片地址；卸载后由站长维护留存图片，不能按文件日期盲删。

请勿在反馈、Git或安装包中附带密钥、AccessKey、验证码、完整手机号、数据库或私有日志。依赖保留各自许可证；公安备案图标来自[深圳市公安局公开素材](https://ga.sz.gov.cn/images/ga_beian.png)。
